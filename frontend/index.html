Need Details?

What Valido handles best

Recurring, text-based PDFs with stable layouts where deterministic validation and auditability matter.

Extraction and validations in plain terms

Use labels to extract values, then add checks like must-contain, must-not-contain, signature, page count, and data type constraints.

Calculations and tolerance checks

Combine extracted fields with formulas and compare expected versus actual values using threshold/tolerance logic.

Current limitation to keep in mind

Valido is not optimized for complex row-by-row table extraction or full invoice line-item capture.

Fix Most Issues In Under 5 Minutes

Start with file quality and exact label matching. Most failures come from image PDFs or mismatched search text.

Field not found

  • Copy label text directly from PDF.
  • Remove leading/trailing spaces.
  • Match punctuation exactly (for example :).

Scanned or image PDF

  • Try selecting text in your viewer.
  • If selection fails, run OCR first.
  • Prefer native digital PDFs for automation.

Wrong value captured

  • Use more specific anchor text.
  • Change extraction strategy (first/last/all).
  • For table contexts, define the column target.

Calculation fails

  • Confirm all formula fields extracted.
  • Use exact field names from output.
  • Set numeric fields to Number type.

Pre-Support Checklist

  1. Test with 1-2 representative PDFs first.
  2. Verify text is selectable in source files.
  3. Copy exact labels from PDF into rules.
  4. Check output once, then scale batch size.
