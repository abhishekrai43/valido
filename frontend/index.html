How To Use Valido

Everything you need to know to validate your documents efficiently

Quick Start

  1. Upload PDFs: Click "Choose Files" or drag PDFs into the upload area
  2. Build Rules: Use the guided wizard to define what to check and extract
  3. Configure Validations: Check for signatures, specific text, page count, etc.
  4. Extract Data: Pull out information like names, dates, amounts
  5. Run Validation: Click "Validate Documents" and wait for results
  6. Download Results: Get a ZIP file with CSV, Excel, PDF reports

Document Validations

Check document properties:

  • Signature Check: Detects if document is digitally signed
  • Must Contain Text: Ensures specific text is present (e.g., "PAID", "Approved")
  • Must NOT Contain Text: Rejects documents with unwanted text (e.g., "DRAFT", "VOID")
  • Page Count: Validates number of pages (at least, at most, exactly)
  • Case Sensitivity: Choose whether text matching should be exact or flexible

Extract Information

Pull data from your documents:

  • Add Field: Extract text, numbers, or dates by searching for labels
  • Extract Between Words: Get text between two markers (e.g., "Invoice #" to "Date")
  • Field Types: Text, Number, Date with automatic type detection
  • Validations: Set rules like min/max length, number ranges, date boundaries
  • Multi-Column Tables: Extract from specific table columns
  • Strategies: Choose first, last, or all occurrences when text appears multiple times

Calculations

Perform math on extracted values:

  • Simple Formulas: Gross Salary - PF - Income Tax
  • Percentages: Basic Salary * 15% calculates 15%
  • Field Names: Use plain field names, no special syntax needed
  • Validation: Verify calculations match expected values
Example: "Net Salary = Gross Salary - PF - Professional Tax"

Batch Processing

  • Small Batches (Browser Upload): Select multiple files at once (Ctrl+Click or Cmd+Click). Maximum 2000 pages total.
  • Upload ZIP Files: Package all PDFs in a ZIP for easier upload
  • Large Batches (Watch Folders): Need to process more than 2000 pages? Set a folder to watch and schedule validation. No page limit.
  • Results: Get individual results for each document in CSV, Excel, and PDF format
  • Pass/Fail Summary: See which documents passed and which failed at a glance

Watch Folders (Automation)

Set up automatic validation for folders:

  1. Go to "Automation" tab
  2. Click "Create Watch Folder"
  3. Select folder to monitor
  4. Choose saved ruleset
  5. Set schedule (e.g., every hour, daily at 9 AM)
  6. Valido automatically validates new PDFs and saves results
Perfect for recurring document validation (daily reports, invoices, etc.)

Understanding Results

Your results ZIP file contains:

  • summary.csv: Plain text results, opens in any spreadsheet app
  • results.xlsx: Formatted Excel with summary and detailed sheets
  • summary.pdf: Beautiful PDF report with branding
  • results.json: Raw data for developers/integrations
  • PASS/FAIL: Clear status for each document
  • Extracted Data: All fields you requested from your documents
  • Validation Details: Which checks passed/failed with reasons

✅ Tips & Best Practices

  • Save Rulesets: Create and save rules you use frequently
  • Test First: Try with 1-2 documents before batch processing hundreds
  • Text-Based PDFs Only: Scanned images won't work (must be text-based PDFs with selectable text)
  • Clear Field Names: Use descriptive names when extracting data
  • Check Results: Always review the summary before relying on automated results
  • Your Data Stays Local: All processing happens on your computer - nothing uploaded to the cloud

🔧 Common Issues & Solutions

Having trouble extracting data or getting unexpected results? This guide covers the most common issues and how to fix them.

No Text Extracted / Field Not Found

Most Common Cause: Leading or trailing spaces, or the PDF is image-based

⚠️ #1 Rule: Copy-Paste from PDF

ALWAYS copy the exact text you want to extract directly from the PDF and paste it into the "Text to Look For" field. This ensures you match exactly what's in the document.

Step-by-Step Fix:

  1. Open your PDF in a viewer (Adobe Reader, browser, etc.)
  2. Select the text label (e.g., "Employee Name:", "Invoice Total:")
  3. Copy it (Ctrl+C or Cmd+C)
  4. Paste into "Text to Look For" field in Valido
  5. CRITICAL: Check for leading/trailing spaces
    • Put cursor at start of text - is there a gap before first character?
    • Put cursor at end of text - is there a gap after last character?
    • Remove any extra spaces you find
  6. Check the colon: Does the PDF have "Employee Name:" or "Employee Name" without colon? Match it exactly.

✓ Example

Wrong: "Invoice Number: " (has space after colon)

Right: "Invoice Number:" (exact match from PDF)

💡 Still Not Working? Try Variations!

Every PDF is structured differently. If the exact text doesn't work, try these variations:

  • With/without punctuation: "Total" vs "Total:" vs "Total Amount"
  • Shorter text: Instead of "Total Amount Due:", try just "Total"
  • Different nearby text: Try text that appears just before or after the value
  • More unique words: If "Date" appears multiple times, try "Invoice Date" or "Issue Date"

Finding the right search term might take 2-3 tries - that's completely normal!

Is Your PDF Actually an Image?

Problem: Scanned documents or image-based PDFs cannot be processed

How to Test:

  1. Open the PDF in any viewer (Adobe Reader, Chrome, etc.)
  2. Try to select text with your mouse
    • If you can select individual words → ✓ Text-based PDF (works with Valido)
    • If you can only select/highlight entire page or nothing → ✗ Image-based PDF (won't work)
  3. Try copying text: Select and copy (Ctrl+C), then paste into Notepad
    • If actual text pastes → ✓ Works
    • If nothing pastes or garbled text → ✗ Won't work

⚠️ Tricky Case

Sometimes you CAN copy text from a scanned PDF (if it has OCR layer), but the text position doesn't match the visual layout. This causes extraction to fail. If your PDF is a scan, even with OCR, results may be unreliable.

Solution for Scanned PDFs:

  • Use OCR software first: Adobe Acrobat, ABBYY FineReader, or free tools like Tesseract
  • Re-export from source: If possible, export the original document as PDF (not scan)
  • Request digital copies: Ask for native digital PDFs instead of scanned copies

Wrong Value Extracted

Problem: Valido finds the field but extracts the wrong value

Common Causes & Fixes:

  • Label appears multiple times:
    • Example: "Total" appears 3 times in document
    • Fix: Use more specific text like "Invoice Total:" or "Grand Total:"
    • Or: Change strategy to "Last" if you want the final occurrence
  • Multi-column table confusion:
    • Example: Extracting "Amount" but PDF has columns "Quantity", "Unit Price", "Amount"
    • Fix: Enable "Is this field in a multi-column table?" checkbox
    • Specify column: Enter "Amount" or "last" or "3" to get the right column
  • Inconsistent formatting:
    • Some PDFs have "Invoice #: 1234", others "Invoice Number: 1234"
    • Fix: Use shortest common text like "Invoice" then use "Extract Between Words" feature

Date or Number Not Recognized

Problem: Extracted text isn't recognized as date/number

Solutions:

  • Numbers with currency symbols:
    • Valido automatically removes: $, €, £, ₹, commas
    • If still not working, check if PDF has hidden characters
  • Date formats:
    • Supported: MM/DD/YYYY, DD-MM-YYYY, YYYY-MM-DD, Month DD, YYYY
    • Example: "Jan 15, 2024", "15/01/2024", "2024-01-15" all work
  • When in doubt:
    • Use "Text" type instead of "Number" or "Date"
    • Extract as text first, verify it's working
    • Then change type to Number/Date if needed for calculations

Calculations Failing

Problem: Formula gives error or unexpected result

Common Issues:

  • Field names with spaces:
    • ✓ Correct: "Gross Salary - Income Tax" (use exact field name)
    • ✗ Wrong: Don't use quotes, brackets, or special syntax
  • Missing field data:
    • If any field in formula is empty/not found, calculation fails
    • Fix: Verify all fields extract successfully first
  • Field extracted as text:
    • Calculation needs numbers, not text
    • Fix: Change field type to "Number" when adding field
  • Percentages:
    • Use: "Basic Salary * 0.15" for 15%
    • Or: "Basic Salary * 15%" - both work

Slow Performance / Timeouts

Problem: Processing takes too long or times out

Solutions:

  • Batch size:
    • Process 50-100 documents at a time
    • For larger batches (>2000 pages), use Watch Folders instead of browser upload
  • PDF size:
    • Very large PDFs (100+ pages each) take longer
    • Consider splitting large PDFs if possible
  • Complex rules:
    • Extracting 20+ fields takes longer than extracting 5
    • Start simple, add fields as needed

Troubleshooting Checklist

Before reporting a bug, try these steps:

  1. Open the PDF in a viewer and verify you can copy-paste text successfully
  2. Copy exact text from PDF and paste into "Text to Look For" - don't type it manually
  3. Remove leading/trailing spaces from the pasted text
  4. Check for special characters (colons, dashes, periods) and match them exactly
  5. Test with 1-2 PDFs first before batch processing
  6. Verify field types (Text/Number/Date) match the data you're extracting
  7. Use simple field names without special characters
  8. Check the results - sometimes "wrong" data is actually correct from Valido's perspective

💡 Pro Tip

Save time by testing your ruleset on 1-2 sample documents first. Verify all fields extract correctly before processing hundreds of documents. Once you have a working ruleset, save it for reuse!
