How To Use Valido

Everything you need to know to validate your documents efficiently

Quick Start

  1. Upload PDFs: Click "Choose Files" or drag PDFs into the upload area
  2. Build Rules: Use the guided wizard to define what to check and extract
  3. Configure Validations: Check for signatures, specific text, page count, etc.
  4. Extract Data: Pull out information like names, dates, amounts
  5. Run Validation: Click "Validate Documents" and wait for results
  6. Download Results: Get a ZIP file with CSV, Excel, PDF reports

Document Validations

Check document properties:

  • Signature Check: Detects if document is digitally signed
  • Must Contain Text: Ensures specific text is present (e.g., "PAID", "Approved")
  • Must NOT Contain Text: Rejects documents with unwanted text (e.g., "DRAFT", "VOID")
  • Page Count: Validates number of pages (at least, at most, exactly)
  • Case Sensitivity: Choose whether text matching should be exact or flexible

Extract Information

Pull data from your documents:

  • Add Field: Extract text, numbers, or dates by searching for labels
  • Extract Between Words: Get text between two markers (e.g., "Invoice #" to "Date")
  • Field Types: Text, Number, Date with automatic type detection
  • Validations: Set rules like min/max length, number ranges, date boundaries
  • Multi-Column Tables: Extract from specific table columns
  • Strategies: Choose first, last, or all occurrences when text appears multiple times

Calculations

Perform math on extracted values:

  • Simple Formulas: Gross Salary - PF - Income Tax
  • Percentages: Basic Salary * 15% calculates 15%
  • Math Functions: sqrt, log, abs, round, floor, ceil, sin, cos, tan, exp, pow, min, max
  • Field Names: Use plain field names, no special syntax needed
  • Validation: Verify calculations match expected values
Example: "Net Salary = Gross Salary - PF - Professional Tax"

Batch Processing

  • Small Batches (Browser Upload): Select multiple files at once (Ctrl+Click or Cmd+Click). Maximum 2000 pages total.
  • Upload ZIP Files: Package all PDFs in a ZIP for easier upload
  • Large Batches (Watch Folders): Need to process more than 2000 pages? Set a folder to watch and schedule validation. No page limit.
  • Results: Get individual results for each document in CSV, Excel, and PDF format
  • Pass/Fail Summary: See which documents passed and which failed at a glance

Watch Folders (Automation)

Set up automatic validation for folders:

  1. Go to "Automation" tab
  2. Click "Create Watch Folder"
  3. Select folder to monitor
  4. Choose saved ruleset
  5. Set schedule (e.g., every hour, daily at 9 AM)
  6. Valido automatically validates new PDFs and saves results
Perfect for recurring document validation (daily reports, invoices, etc.)

Understanding Results

Your results ZIP file contains:

  • summary.csv: Plain text results, opens in any spreadsheet app
  • results.xlsx: Formatted Excel with summary and detailed sheets
  • summary.pdf: Beautiful PDF report with branding
  • results.json: Raw data for developers/integrations
  • PASS/FAIL: Clear status for each document
  • Extracted Data: All fields you requested from your documents
  • Validation Details: Which checks passed/failed with reasons

Privacy & Security

  • 100% Local: Valido runs entirely on your computer
  • No Cloud Upload: Your PDFs never leave your system
  • No Internet Required: Works completely offline
  • Your Data, Your Control: All processing happens locally
  • No External Services: No data sent to third parties
  • Instant Processing: Fast validation without network latency

Tips & Best Practices

  • Save Rulesets: Create and save rules you use frequently
  • Test First: Try with 1-2 documents before batch processing hundreds
  • Text-Based PDFs Only: Scanned images won't work (must be text-based PDFs)
  • Clear Field Names: Use descriptive names when extracting data
  • Batch Wisely: Process 50-100 docs at a time for best performance
  • Check Results: Always review the summary before relying on automated results

Troubleshooting

  • No text extracted: PDF might be image-based (scanned). Valido extracts text from text-based PDFs only
  • Wrong data extracted: Use more specific search terms (e.g., "Invoice Total Amount" instead of "Total")
  • Multi-column tables: Use the column selector to specify which column to extract from

Mixed Environment? Even if your team uses Mac systems, you can run Valido on a single Windows PC. Users can access it over the network from any device (Mac, Windows, Linux) using just a web browser. Results are stored on the Windows PC and accessible to all network users.
