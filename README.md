# Valido – PDF Validation & Data Extraction Tool

**Valido** is a desktop application for validating and extracting data from PDF documents using customizable rules.

---

## 🖥️ Platform

- **Windows Only** (Windows 10/11)
- Accessible throughout your **Local Area Network (LAN)**
- No internet connection required for operation

---

## ✨ Key Features

### 📄 Smart PDF Processing
- Extract text and data from PDF documents
- Build custom validation rules using an intuitive wizard
- Extract text between specific words or patterns
- Handle single PDFs or bulk process multiple files

### 🤖 Automation Support
- **Watch Folders**: Automatically process PDFs placed in monitored folders
- **No Manual Upload Required**: Set up folders and let Valido handle the rest
- Batch processing of ZIP files containing multiple PDFs
- Scheduled processing and background operations

### 🌐 LAN Access
- Run on one computer, access from any device on your network
- Share validation results across your team
- Centralized rule management
- Web-based interface – no installation needed on client machines

### 🛠️ Built-in Help
The application includes a comprehensive **"How To Use"** section with:
- Step-by-step guides for creating rules
- Examples and best practices
- Troubleshooting tips
- Interactive wizard tutorials

---

## 🚀 Quick Start

1. **Install** Valido on a Windows machine
2. **Launch** the application
3. **Access** the web interface from any device on your LAN at `http://[server-ip]:8000`
4. Follow the **"How To Use"** section in the app for detailed guidance
